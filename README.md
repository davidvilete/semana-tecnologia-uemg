# 💻 Trabalho Avaliativo P2 — Fundamentos de Programação para Web

Repositório destinado às entregas individuais do **Trabalho Avaliativo P2** da disciplina de **Fundamentos de Programação para Web**, ministrada pela **Profª. Clarete Aparecida Diniz Gomes** (2º período de Sistemas de Informação — UEMG).

---

## 📋 Sobre o Projeto

Desenvolvimento de uma página web para divulgação da **Semana de Tecnologia da UEMG**, aplicando conceitos fundamentais de estruturação, estilização e interatividade no lado do cliente:

* **HTML5:** Estruturação semântica contendo título, subtítulo, parágrafo de apresentação, lista de minicursos com cargas horárias e links de navegação (`Início`, `Minicursos` e `Contato`).
* **CSS3 (Externo):** Estilização via seletores de elemento, classe e ID, pseudo-classes (`:hover`, `:visited`) e pseudo-elemento (`::first-letter`).
* **JavaScript (Externo):** Interatividade com caixas de diálogo (`prompt()`, `alert()`, `confirm()`) e manipulação dinâmica do DOM (`document.body.style.backgroundColor`).

## 📂 Como enviar o seu trabalho (Instruções para a turma)

Para evitar que os arquivos de um aluno sobrescrevam os de outro, siga o padrão abaixo ao fazer o upload ou *commit*:

1. Crie uma pasta na raiz do repositório com o seu **nome e sobrenome** em letras minúsculas e separadas por hífen (ex.: `emannuely-vanuzia/`).
2. Dentro da sua pasta, adicione os **3 arquivos obrigatórios**:
   * `index.html`
   * `style.css`
   * `script.js`
3. Certifique-se de que a página abre corretamente no navegador localmente e que todas as funcionalidades estão operando conforme o enunciado.
